# Alaska AI - Case Files

The lead magnet content engine. A daily routine that produces one
post-ready LinkedIn carousel breaking down a verified story of an everyday
company winning with a targeted AI build on a specific bottleneck, with
receipts, the honest catch, and an Alaska translation, delivered as a Gmail
draft for the maintainer to post by hand. Showing instead of asking is the
entire sales strategy.

STATUS. The machine is built and proven, the trigger is not yet created.
The engine renders and QA-passes in this repo (samples/engine-proof, vector
PDF), the caption and style lints pass on the sample post, the delivery
script is smoke-tested, and the bank holds 16 verified-at-intake cases.
One manual step remains, wiring the daily trigger, see docs/LAUNCH_PLAN.md.

## The idea in four lines

- Ordinary companies. One bottleneck. A targeted build. Real numbers.
- Every post teaches the whole lesson free, receipts and limits included.
- Every post ends with the same calm standing offer, no gimmicks.
- The honesty machinery (labels, ranges, base rates, a critic that
  defaults to reject) is the moat no generic AI content shop can copy.
