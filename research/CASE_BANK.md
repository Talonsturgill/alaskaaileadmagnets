# The Case Bank (human digest)

The machine bank of record is ledger/bank.json. This file is the readable
digest. 16 cases researched and fetched 2026-07-21, every number read on a
live page, every case carrying a skepticism note and an evidence strength.
The routine's own fact-checker re-verifies a case fresh before it ships, a
candidate here is raw material, not a cleared post.

Rule of the bank. Strong ships on its own. Medium ships with its labels said
plainly. Weak never headlines, it can appear inside a capability file with the
vendor framing explicit, or it waits for corroboration.
